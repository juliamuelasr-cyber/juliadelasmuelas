# Music mood recommender

Soy una apasionada de la música; creo que es esencial en nuestra vida diaria, ya sea para concentrarse mientras trabajamos, para disfrutar momentos con amigos, para relajarse, o incluso para llorar. Por eso he decidido crear este proyecto, combinando Python con mi playlist con mis canciones favoritas clasificada en moods.

Utilizo estructuras de datos como diccionarios y listas para interactuar con el usuario de una manera creativa.
